# Artwork

项目全部素材的工作副本（SVG，自制）。随应用包提交的副本在
`bundle/assets/`（`main.splash` 以 `{{assets}}/assets/…` 引用）；两处应保持
一致——修改此处后同步到 `bundle/assets/`，再 `hub stamp`。

- `av-*.svg` 姓氏渐变圆头像（张/李/王/赵/陈/孙/林，姓氏以路径烘焙，无 `<text>`）
- `nav-*.svg` 底部导航图标（收件箱/待办/AI 助手/我的/写信）
- `ai-star.svg`（白）/ `ai-star-orange.svg` AI 星标
- `banner-art.svg` 横幅插画、`search-grey.svg`、`flag-red.svg`、
  `clock-purple.svg`、`icon.svg` 应用图标（纯形状，见 App Hub ICONS 规则）

配色含义见 `source/design-brief.md`。
